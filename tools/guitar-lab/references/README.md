# Guitar Lab references

In Guitar Lab press **📁 Choose folder** and select this folder
(`MyDAW\tools\guitar-lab\references`). From then on every **⭐ Save as reference**
writes here:

| File | Content |
|---|---|
| `guitar-references.json` | The chosen settings of each guitar (nylon, steel, strat, lespaul, hollow) — the file ScoreDAW will use when the engines are integrated. |
| `guitar-lab-state.json` | The whole lab (all variants A–D, ratings, notes, saved experiments). Can be re-imported with **Import JSON**. |
